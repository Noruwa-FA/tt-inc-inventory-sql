# T.T Inc. Inventory Optimisation - SQL Capstone

**Tools:** SQL (PostgreSQL)
**Completed:** February 2025

## Project Overview
SQL capstone project for a consumer electronics company, using PostgreSQL to analyse inventory, sales, and external economic data to inform supply chain strategy.

## What I Did
- Joined three datasets (sales, product information, and external economic indicators) to build a unified analytical view of inventory performance
- Wrote aggregate queries to calculate total units sold per SKU, average sales by product category, and top 10 best-selling products
- Analysed the correlation between GDP, inflation rate, seasonal factors, and sales volume using GROUP BY and HAVING clauses
- Assessed promotional impact on sales quantity and calculated inventory turnover, optimal reorder levels, and total holding cost

## Key Skills Demonstrated
- PostgreSQL: multi-table JOINs, aggregate functions, GROUP BY, HAVING
- Supply chain analytics: inventory turnover, reorder level calculation
- Economic indicator correlation analysis
- Business insights and recommendations from SQL outputs
