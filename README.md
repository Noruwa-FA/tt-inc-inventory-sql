# T.T Inc. Inventory Optimisation - SQL Capstone

**Tools:** SQL (PostgreSQL)
**Completed:** February 2025

## Project Overview
SQL capstone project for a consumer electronics company, using PostgreSQL to analyse inventory, sales, and external economic data to inform supply chain strategy.

## What I Did
- Joined three datasets (sales, product information, and external economic indicators) to build a unified inventory performance view
- Wrote aggregate queries to calculate total units sold per SKU, average sales by category, and top 10 best-selling products
- Analysed the correlation between GDP, inflation rate, seasonal factors, and sales volume
- Calculated inventory turnover, optimal reorder levels, and total holding cost using industry-standard formulas

## SQL Files
- `sql/01_sales_analysis.sql` — Units sold per SKU, top 10 products, category averages
- `sql/02_promotional_analysis.sql` — Promotional impact on sales quantity
- `sql/03_economic_indicators.sql` — GDP, inflation and seasonal factor correlation
- `sql/04_inventory_calculations.sql` — Turnover rate, reorder levels, overstock/understock risk

## Key Skills Demonstrated
- PostgreSQL: multi-table JOINs, GROUP BY, HAVING, aggregate functions
- Supply chain analytics: inventory turnover, reorder level calculation
- Economic indicator correlation analysis
